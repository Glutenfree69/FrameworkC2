# An NSIS installer script

[NSIS](https://nsis.sourceforge.io/Main_Page) is a scripting language that you can use to create windows installers. In the installer folder, there is an NSIS script that 
- Installs a malware loader (source code [here](https://github.com/Glutenfree69/FrameworkC2)) 
- Installs a legitimate Sublime Text version as a decoy
